Every experiment gets an ID: `EXP-{CATEGORY}-{NUMBER}`. It's overkill for a personal site, but it makes the whole thing feel like an actual lab notebook instead of a blog — and it makes it easy to reference one experiment from another.

| Prefix | Category |
|---|---|
| `EXP-CV` | Computer vision |
| `EXP-LLM` | LLMs / RAG |
| `EXP-PERF` | Cross-cutting performance (CPU vs GPU, quantization, runtimes) |
| `EXP-MLOPS` | Training pipelines, data, deployment |

## Every experiment follows the same shape

Use [the template](/experiments/template) as the starting point for a new one. The sections always run in this order:

`Hypothesis → Setup → Control Variables → Metrics → Results → Analysis → Verdict`

Keeping the structure identical across every write-up is deliberate — it's what makes experiments comparable to each other, and it's what stops a "results" section from quietly turning into marketing copy.
